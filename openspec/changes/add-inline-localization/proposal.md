# Proposal

Статус: реализация согласована пользователем 2026-10-06. Пользователь подтвердил базовый prototype/reveal/Copy/Undo и разрешил NLS-этап. В локальном dev реализованы реальные ресурсы, настройки, presentation, Warning и hover/definition. Итоговый editor matrix остаётся pending; localization completion реализован по add-i18n-toolkit 3.1; создание нового ресурса/rename не реализованы, релиза нет.

## Why

Ключи вида `"$Workspace.title$"` мешают читать отображаемые названия прямо в BL. Пользователь хочет видеть перевод вместо ключа по умолчанию, сохраняя ключ в исходнике и предупреждения об отсутствующих языках.

## What Changes

- Визуально заменять локализационный ключ переводом без изменения BL-файла.
- По UX revision 2026-10-06 оформить замену мягко, в стиле inlay hint: приглушённый
  текст/фон темы, без контрастной рамки; light/dark/high contrast и смена темы.
- Включить этот режим по умолчанию; язык из настроек плагина, default `ru`.
- Раскрывать исходный ключ для редактирования и давать переключение «переводы / ключи».
- Показывать missing translations как Warning, не Error; не подставлять другой язык молча.
- Проверять отдельно настраиваемый список необходимых языков проекта.
- Добавить переход в ресурс, completion ключей и явно запрошенное добавление/rename через preview.

## Capabilities

### New Capabilities

- `inline-localization`: языковой индекс ресурсов, отображение переводов и проверка полноты локализаций.

### Modified Capabilities

Нет: диагностические ошибки BL и текущие CodeLens остаются независимыми.

## Impact

Появятся индекс `.nls`, наблюдение за ресурсами, presentation layer и отдельная warning-диагностика. Визуальная замена требует прототипа курсора/выделения/копирования; если безопасно выполнить контракт нельзя, нужен новый согласованный дизайн, а не скрытая подмена фичи hint-ом.

## Non-goals

Не сохранять переводы в BL вместо ключей; модельное переведение и multi-locale editor
планируются отдельно в `add-i18n-toolkit`, не реализуются этим change; не менять runtime locale пользователя, не добавлять автоматический language fallback.
