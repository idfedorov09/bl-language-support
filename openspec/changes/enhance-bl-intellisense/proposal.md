# Proposal

Статус: планирование. Реализация не начата и требует отдельного запроса.

## Why

В версии 1.1.0 уже есть локальный индекс, навигация, поиск использований и эвристическая диагностика. Следующий шаг — дополнить это ядро средствами написания BL, не выдавая существующий индекс за полноценный IntelliSense или компилятор.

## What Changes

- Добавить контекстное completion классов, полей, методов, записей и импортов.
- Добавить signature help с перегрузками и auto-import с выбором неоднозначного класса.
- Добавить структуру документа, семантическое различение символов и rename с предварительным просмотром.
- Сохранить существующую навигацию, настройки диагностики и работу с несохранёнными зависимостями.
- Типизированная проверка настоящим BL-компилятором остаётся отдельным исследованием, а не обещанием этой итерации.

## Capabilities

### New Capabilities

- `bl-intellisense`: помощь при написании BL поверх существующего ядра.

### Modified Capabilities

Нет: текущие contracts навигации и диагностики сохраняются.

## Impact

Новые editor providers используют данные существующего индекса. Потребуются проверки completion/signature/symbols/rename и расширение mock VS Code API. Публичные команды и настройки версии 1.1.0 не удаляются.

## Non-goals

Не переписывать расширение на Java/LSP, не обещать полный type checker, не реализовывать JS-маршруты, HTTP-вызовы или генераторы в рамках этого изменения.
