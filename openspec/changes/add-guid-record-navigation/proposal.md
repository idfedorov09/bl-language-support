# Proposal

Статус: реализация начата по отдельному запросу пользователя 2026-10-06; проверенные задачи отмечаются в tasks.md. Версия и публикация не меняются; UI-проверка отдельно не согласована.

После ручной проверки пользователя 2026-10-06 отдельно согласованы UX-правки и расширение lookup на статические `static final guid`-константы. Скриншоты — feedback, не доказательство прохождения всего editor gate.

## Why

Имена `records` уже индексируются как BL-члены типа `guid`. Но значение GUID пока не ведёт к записи и не объясняет её назначение; для этого приходится искать литерал вручную.

## What Changes

- Добавить поиск декларации по GUID-значению и переход из GUID-литерала.
- Показывать карточку записи: имя, владелец, атрибуты, источники и известные связанные записи.
- Находить использования символа и GUID, различая эти два вида совпадений.
- Подсвечивать подтверждённые или подозрительные конфликты без глобального правила «любой повтор UUID — ошибка».
- Предоставить lookup для ответов Request Workbench, не обращаясь к БД.
- Искать также статические GUID-константы, явно отличая их от `records`.
- Заменить InputBox на Quick Pick с поиском по части GUID/имени/владельцу; промежуточный ввод не ошибка.
- Сделать hover компактным, с рабочими действиями, а поиск использований — с видимым прогрессом/результатами.
- Сгруппировать BL-команды контекстного меню в подменю Z8BL, сохранив палитру и command IDs.
- Открывать карточку/использования новой вкладкой в текущей группе редактора, без автоматического сплита.

## Capabilities

### New Capabilities

- `guid-record-navigation`: индекс GUID-значений и исследование статических записей.

### Modified Capabilities

Нет: обычная BL-навигация по именам `records` уже существует и сохраняется.

## Impact

Дополнительные сведения статических записей будут храниться в рамках выбранного checkout. При наличии локализаций и request-инструментов их данные могут дополнять карточку, но lookup не требует этих блоков или сетевого подключения.

## Non-goals

Не строить полноценный обозреватель прав, не утверждать фактический доступ пользователя, не искать произвольные записи в runtime-БД, не менять существующие GUID автоматически.
